# 01 · 定位与术语

## 它是什么

`nmrforge_api` 是 NMRForge 对外提供的**研究用接口**(不是一个新软件):无 GUI、
不依赖 Qt、可在无显示环境或集群上运行,把一个「处理参数 → 峰位不确定度」的研究
流程固化成一条可复算的流水线。

它复用的是 NMRForge 自身的处理与判读口径:

- 处理:同一套 NMRPipe 脚本生成与执行(统一相位优化等);
- 峰位:与 NMRForge 选峰**同一套** ppm 轴映射(ORIG 优先、回退 CAR,按
  FDDIMORDER 把逻辑维映射到数据轴);
- 记录:每个 WorkflowRun 都带 NMRForge/依赖/NMRPipe 版本与脚本快照。

## 它解决什么

单次处理只能给你一张谱;要回答「处理参数把峰位挪动了多少」,需要:

1. 一个**参考**:参考谱 + 参考脚本 + 参考峰位(都由软件自动优化产生);
2. **控制变量**:同一份 fid、同一相位,只改被扫参数;
3. **连续观测量**:同一批峰在每张候选谱上的位置(不是重新选峰);
4. **汇总指标**:逐峰 σ、Δδ 下限,以及数据集级的分布;
5. **可复算**:脚本/谱的哈希、参数、版本、网格一次性落盘。

这五件事就是本接口的全部内容。

## 它不做什么

- 不做峰归属/指认(可用外部峰表叠加,但默认不参与);
- 不做峰重叠解耦与去卷积(v0.1 只做局部极值 + 抛物线 refine);
- 不做 NUS/SMILE 参数扫描(v0.1 仅 uniform,见
  [09-limitations-and-roadmap.md](09-limitations-and-roadmap.md));
- 不做并行调度(串行 + 断点续跑;分片策略见第 9 节);
- 不替代论文级的统计推断:σ 与 Δδ 下限是**描述性**指标,显著性检验请在你的
  分析侧按样本量/分布假设做。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 研究根(root) | 一个目录 = 一个研究项目 = 一个 NMRForge 项目(`project.json`),内含 `study/` |
| 数据集(DatasetRef) | 导入研究项目的一个 Bruker 原始数据集(`exp_id/data_id`) |
| 参考谱 | NMRForge 自动优化跑出的谱,冻结在 `study/reference/<exp>_<data>/reference.ft2` |
| 参考脚本 | 参考运行**实际执行**的 NMRPipe 脚本,冻结为 `process.com`(带 SHA-256) |
| 参考峰位 | 软件在参考谱上自动选出的峰(或外部峰表),冻结为 `reference.list` |
| 组合(combo) | 参数网格的一个取值点,如 `{"window.F1.off": 0.45, "zero_fill": 2}` |
| 候选谱 | 某组合跑出的谱,存 `study/runs/<run_id>/spectrum.ft2`,**不替换**参考谱 |
| 峰位测量 | 在候选谱上按参考峰位附近 ±window 点找极值并做亚像素 refine |
| σ_n | 某核峰位在各组合间的样本标准差 |
| Δδ 下限 | `sqrt(Σ_n (w_n·σ_n)²)`,w(1H)=1、w(15N)=`csp_n_weight`(默认 0.2) |
| run_id | 组合编号 `s0001`, `s0002`, …(与项目里的 WorkflowRun `R-…` 不同) |

## 运行语义(六条硬约束)

1. **不 import Qt / 不改 GUI 状态**——可在集群运行,有专项测试守护;
2. **fid 只转换一次**——所有组合复用同一份 fid,参数是唯一变量;
3. **相位锁定参考值**——直接维跳过相位搜索、间接维沿用参考优化相位;
4. **候选谱不落活动谱**——只写 `study/runs/`,参考谱与项目状态不受影响;
5. **可断点续跑**——每个组合成功即写 `run.json`,重跑跳过已成功组合;
6. **单组合失败不中断**——状态 `failed` + 原因落盘,继续下一组合。
