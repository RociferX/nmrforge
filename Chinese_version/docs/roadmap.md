# 路线图与支持边界

本页说明当前公开支持范围和可能的扩展方向，不是发布计划，也不承诺实现所有列出的设想。已交付变更请查阅公开[发行说明](https://github.com/RociferX/nmrforge/releases)，并在研究中记录所用的源代码/API 版本。

## 当前支持

| 范围 | 当前边界 |
| --- | --- |
| 均匀采样 | 支持 1D、2D 和 3D 处理路径。 |
| NUS | 2D NUS 支持参考构建和通过 SMILE 执行参数组合；3D NUS 当前仅支持参考构建。 |
| 批处理 | 批处理入口仅支持 2D。 |
| 峰定位 | 仅支持一种方法：三点抛物线定位。 |
| 峰重叠/解卷积 | 不提供；各峰分别筛选和定位。 |
| 参数执行 | 按顺序执行用户提供的参数行或网格；软件不会替用户设计研究方案。 |
| 统计推断 | 不属于处理软件的职责；请在下游分析中明确假设并处理缺失数据。 |
| 外部引擎 | NMRPipe 以及 NUS 所需的 SMILE 均需另行安装。 |

详细的处理和 API 契约见[处理模型](processing-model.md)、[峰挑选](peak-picking.md)、[外部 API](external-api/README.md)和[API 契约](API_CONTRACT.md)。

## 可能的扩展方向

以下方向可能值得后续评估，具体取决于用户需求、科学审查以及与现有契约的兼容性；它们目前都不是已支持功能：

- 执行 3D NUS 参数组合；
- 显式选择用于特定维度分析的测量平面；
- 扩展参数键校验，并对不支持的键提供更清晰的错误信息；
- 若有合适的验证数据和输出契约，增加峰形或峰重叠模型；
- 为外部编排提供可选的进度/状态集成。

新增处理算法应使用适当的参考数据进行评估，并记录其局限性。软件运行成功或工程回归测试通过，都不能单独证明科学结论正确。

## 验证与证据

工程测试检查已实现的软件路径及记录的一致性。NMRPipe/SMILE 的执行须在安装了相应工具的系统上另行验证。科学结论需要与具体问题相适配的真实参照数据和分析标准。

[真实数据实测证据](evidence/real-data-comparison.md)当前包含 BMRB 27493 的 2D uniform 作者对照、同源受控人工 2D NUS、BMRB 15750 3D uniform 作者脚本重建谱，以及实采 BMRB 52533 HNCO 3D NUS（25%）四组完成对照。人工 NUS 是 uniform 原始数据的受控下采样，不是实采 NUS。15750 按谱头 CAR 差作固定整轴平移；证据页逐例注明输入、参考来源和边界。
