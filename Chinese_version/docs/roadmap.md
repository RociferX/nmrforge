# 能力与限制

## 处理支持

| 操作 | 桌面工作流 | Python/CLI API |
| --- | --- | --- |
| 2D uniform | 自动与人工处理 | 参考构建与参数组合 |
| 2D NUS | 自动/人工SMILE重建；SMILE优化与按排名重跑 | 参考构建与参数组合 |
| 3D uniform | 自动与人工处理；完整谱或支持的平面输出 | 参考构建与参数组合 |
| 3D NUS | 自动与人工SMILE重建 | 参考构建；组合执行拒绝 |
| 批量操作 | 2D数据组 | 显式workflow/条件组合，支持续跑 |
| 峰定位 | 三点抛物线 | 三点抛物线，可指定目标子集 |
| 查看 | 一维谱/FID、二维谱、三维切片/投影 | 无Qt的谱图/峰表产物 |

NMRPipe负责转换与常规处理，SMILE负责NUS重建，两者均需另行安装。
桌面与API使用相同后端，入口的参数合并、产物登记及续跑逻辑不同。

## 数据与参数边界

- Bruker元数据提供维度身份、采集模式、校准与采样证据。NUS使用标准或明确指定的采样表，不从比例猜缺失位置。
- 转换设置决定FID。API组合复用冻结参考FID，不能改变转换校准或静默重转/合并源数据。
- 人工脚本开放处理命令，运行保留实际执行文本与结果。
- API参数行/网格由调用者显式输入。运行串行执行并续用成功工作；调用者可拆分网格到独立研究根。

## 峰表与解释

API逐workflow/条件独立检测峰，写入38列峰表；峰ID只在单谱内有效。
软件不做自动指认、跨谱匹配、重叠去卷积、Lorentzian/Voigt/多峰拟合或统计推断。
同核重复维度需使用完整逻辑轴坐标，H/N别名单独使用可能有歧义。
检测阈值、噪声、相位与峰形会影响候选筛选和定位QC。

## 检查与证据

工程测试通过模拟引擎检查编排与记录；真实引擎对照另行保存输入、参考来源、命令、参数及终谱。
[四路径证据](evidence/real-data-comparison.md)包括作者二维uniform参考、保留68/90增量的受控人工二维NUS、
作者脚本重建完整三维uniform参考，以及实采25%的三维NUS。
候选覆盖率为匹配对数/参考候选数，不统计已指认三维峰身份。
详见[API支持细节](external-api/09-limitations-and-roadmap.md)、[处理模型](processing-model.md)和[选峰](peak-picking.md)。
