# 图形界面指南

桌面程序是处理谱图的正式界面。本页是界面的导览;底层引擎的行为见
[processing-model.md](processing-model.md) 与 [qc-system.md](qc-system.md)。

![nmrForge 主窗口](../../gui/assets/nmrforge.png)

> **语言说明:本页是中文文档。** 英文是界面的源语言,菜单与面板默认是英文;同一份构建也带
> 中文界面(跟随系统语言,在「设置 → 软件设置 → 界面语言」里选,或用 `NMRFORGE_LANG=zh`
> 临时钉死)。中文文案在
> [`ui_support/locales/zh.json`](../../ui_support/locales/zh.json),与英文版是**同一份代码**。

## 启动

```bash
python main.py    # v1.0.0 源码入口(AppImage 里是内置入口)
```

v1.0.0 的 Linux AppImage 在发布页(一份产物,界面语言运行时切换);首次正常运行会装桌面菜单项
(`--remove-desktop` 移除),构建与验收记录见 [packaging.md](packaging.md)。

## 窗口布局

窗口是**四列**(列边界可拖;视图菜单只控制其中三列的显示):

| 列 | 显示内容 |
| --- | --- |
| 第 1 列 | 项目树:项目 -> 实验 -> 输入 / 处理 / 输出 / 图形。选中节点即为其余面板设定上下文。 |
| 第 2 列 | 所选数据集的处理流水线:面包屑,加上按状态驱动的步骤列表与「下一步做什么」提示。 |
| 第 3 列 | 任务日志,常驻的中间竖列,范围随当前选择(单数据集、数据组、实验类型或全局)。 |
| 第 4 列 | 谱图面板:内嵌查看器,以及当前上下文已产出的谱图列表。 |

菜单:`文件`(新建/打开/保存项目、最近项目)、`实验`(新建/重命名/删除实验)、
`查看`(收起/展开 项目树 / 流水线 / 谱图)、`工具`(数据质量检测、谱图质量评估)、`设置`(软件设置)、
`帮助`(使用教程、关于)。**`帮助 → 使用教程`** 弹出随包的教程文档(有哪些功能、怎么用,按当前界面语言),正文在 `nmrforge_data/tutorial/{zh,en}.md`。

## 处理流水线

四个步骤,每步一个状态 —— `未就绪`(锁定,前置条件未满足)、`可运行`(就绪)、`运行中`、
`已完成`、`失败`、`已过期`(事后输入或参数变化):

| 步骤 | 标签 | 做什么 |
| --- | --- | --- |
| 1 | 生成 FID | 把原始 Bruker 数据转换为 NMRPipe FID(用生成的 `fid.com` 跑 `bruker -AUTO`)。 |
| 2 | 生成谱图 | 执行优化后的处理路径,含 NUS 数据的 SMILE 重构。 |
| 3 | SMILE 优化 | 可选:对重构参数候选做扫描排名。仅 2D NUS;它不会自动替换活动谱。 |
| 4 | 峰挑选 | 自动选峰,并评估强度与 S/N。 |

步骤按顺序解锁。已完成步骤的输入或参数发生变化后会被标为 `已过期`,而不是被静默复用 ——
该步骤会记录自己的输入、脚本与参数指纹。

## 一次典型会话

1. **新建或打开项目**,然后**导入**一个 Bruker 数据目录(在项目树里右键实验节点 ->
   「导入样品数据...」)。只接受含 Bruker 参数文件的目录;同一实验的多个分段会作为该实验的
   不同 run 提供。
2. **核对理解结果**:实验类型及其证据、采样分类与维度布局。如果分类不对,可以在处理前修正
   实验模板 —— 这比处理完再补救便宜得多。
3. **生成 FID**,再**生成谱图**。数据质量检测先跑,结论在任何优化步骤之前写进日志。
4. **读运行结束时的报告**:最终谱图质量(信噪比、相位、基线与伪影分项)、数据质量检测一节,
   以及解析后的处理参数(包括优化器自己选的)。
5. **在右侧面板查看谱图**:鼠标缩放、中键平移、叠加谱图,点峰表里的行可以跳到对应峰。
6. **选峰**并导出峰表(POKY 风格)。谱图也可以导出为 UCSF 供其它软件使用。
7. **手工路径** —— 任何生成的脚本都能在脚本编辑器里打开、修改并直接运行。改脚本是一次有意
   为之的覆盖,因此会与自动运行分开记录。

## 数据组与批量处理

数据可以组织成数据组一起处理:导入时勾选「批量导入并成组(仅支持 2D 谱)」,或在项目树里右键
数据组节点增删成员,然后对整组一起处理。批量处理**仅支持 2D**:非 2D 数据会被跳过并说明原因;
失败按数据集隔离,单个坏数据不会中断整组。

## 独立查看器

```bash
nmrforge-viewer          # 完成可编辑安装之后
python -m viewer
```

查看器可以拖放打开 `.ft2`/`.ft3` 文件,保留最近文件列表,用强度滑块叠加谱图、标记峰,并支持
带投影的 3D 切片。

## GUI 把东西写在哪里

所有状态都在你选定的项目目录里:项目文件、每个数据集的工作目录、生成的脚本、运行记录与日志。
GUI 从不写入你的原始数据目录;它删除的任何东西都进操作系统回收站,而不是直接抹掉。
