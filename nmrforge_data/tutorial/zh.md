# NMRForge 使用教程

这份教程给第一次用图形界面的人:先看「能做什么」,再照一次典型会话走一遍。
菜单与按钮名称以程序里显示的文字为准。

## 1. 这个程序能做什么

- **读 Bruker 数据**:识别实验类型、采样方式(均匀 / NUS)与维度布局;
- **自动处理**:把原始数据转成 NMRPipe FID、再出谱;相位、基线、窗函数、零填充由程序选;
- **参数优化**:SMILE 参数扫描与排名(仅 2D NUS),可按「净真峰优先」或「留出残差优先」排序;
- **峰挑选与峰表**:自动选峰、抛物线/二维高斯亚像素定位,导出 POKY 风格 `.list`,谱图可导出 UCSF;
- **质量控制**:FID / 采样 / 谱图三级检查,运行结束时给分项报告;
- **项目与留档**:每个数据集的工作目录、生成的脚本、运行记录与日志都放在你的项目目录里;
- **数据组与批量**:把 2D 数据组织成组,一起处理;
- **人工路径**:任何生成的脚本都能打开、修改、直接运行。

## 2. 界面速览

窗口分三栏:

- **左栏 · 项目树**:项目 → 实验 → 输入 / 处理 / 输出 / 图形。选中哪个节点,其余两栏就跟着切换。
- **中栏 · 处理流水线**:当前数据集的四个步骤,每步带状态和「下一步做什么」提示;下面是**任务
  日志**,范围随选择变化(单个数据集 / 数据组 / 实验类型 / 全局)。
- **右栏 · 谱图**:内嵌查看器,以及当前上下文已经产出的谱图列表。

顶部菜单:`文件`、`实验`、`查看`、`工具`、`设置`、`帮助`(关于、使用教程 —— 就是这份文档)。

## 3. 第一次使用:走一遍

1. **新建项目**:`文件 → 新建项目...`,选一个(建议空的)目录,产物都记在这里。
2. **新建实验**:`实验 → 新建实验...`。实验类型可以先填或留空,程序会用数据自己判定。
3. **导入数据**:在左栏右键实验节点 →「导入样品数据...」,选 **Bruker 数据目录**(里面有
   `acqus` 这类参数文件)。同一实验的分段采集可以作为多个 run 导入;2D 数据还能勾选
   「批量导入并成组」。
4. **核对理解结果**:中栏显示实验类型、采样分类与维度布局,证据写在日志里。**分类不对就现在改**,
   比处理完再补救便宜得多。
5. **生成 FID**,再**生成谱图**。数据质量检查会在优化之前先跑,结论写进日志。
6. **读运行结束时的报告**:谱图质量分项(信噪比 / 相位 / 基线 / 伪影)、数据质量检查结论,以及
   最终实际用的处理参数(包括程序自己选的)。
7. **看谱**:右栏查看器滚轮缩放、中键平移、可叠加多条谱;点峰表里的行会跳到对应峰。
8. **峰挑选**,然后导出峰表或把谱导出成 UCSF。
9. 想改处理细节就走**人工路径**:打开生成的脚本、改好、直接运行(人工运行与自动运行分开记录)。

## 4. 四个步骤

### 生成 FID

把原始 Bruker 数据用生成的 `fid.com`(内部调用 `bruker -AUTO`)转换成 NMRPipe FID。
**这一步需要机器上装了 NMRPipe。** 3D 数据按采样网格产出单文件或切片,由程序判断。

### 生成谱图

按优化后的处理路径出终谱;**NUS 数据自动包含 SMILE 重构**。这一步最花时间与内存,日志会写实际
用了哪些参数。

### SMILE 优化(可选,仅 2D NUS)

对重构参数候选做扫描并排名,给出排序表和候选脚本。**它不会自动替换当前的活动谱** —— 看中哪个
候选再自己重跑。3D NUS 能正常处理,但界面不提供这条扫描。

### 峰挑选

自动选峰并估计强度与 S/N;可以只对指定峰做二维高斯精修。峰表能导出成 POKY 风格。

### 状态与「已过期」

每一步有六种状态:**未就绪**(前置条件没满足)、**可运行**、**运行中**、**已完成**、**失败**、
**已过期**。改了输入或参数之后,受影响的下游步骤会被标成「已过期」,而不是继续用旧产物 —— 重跑
那一步就行。

## 5. 看谱

- 右栏内嵌查看器:滚轮缩放、中键平移、强度滑块调等值线、叠加多条谱;
- 3D 数据可以按切片查看,并显示投影;
- **独立查看器**(不需要项目)也能单独启动:装好之后用 `nmrforge-viewer`,或 `python -m viewer`;
  支持把 `.ft2` / `.ft3` 文件直接拖进去。

## 6. 数据组与批量(仅 2D)

把数据组织成数据组,然后对整组一起处理。**批量只支持 2D**:非 2D 数据会被跳过并说明原因;
单个数据集失败不会中断整组。

## 7. 工具菜单

- **数据质量检测**:检查原始 FID 的质量,结论在任何优化之前写进日志;
- **谱图质量评估**:对已有谱图打分,给出分项与结论。

## 8. 设置

`设置 → 软件设置`:

- **界面语言**:跟随系统 / 中文 / 英文(按提示重启程序生效;`NMRFORGE_LANG` 可临时钉死一次运行);
- **NMRPipe 路径**:留空则自动查找(PATH、`~/.cshrc` 里的 `NMRPIPEBIN`、常见安装目录);
- **数据目录**:导入对话框的浏览起点;
- **各核默认线宽**与**对齐容差**:影响自动优化与峰匹配的判据;
- **SMILE 线程数**:默认 2,上限是「机器核数 − 2」;调高更快也更吃资源,NUS 重构建议保守。

## 9. 想自己改脚本

任何一步生成的脚本都能在脚本编辑器里打开、改、直接运行。改脚本是一次**有意的覆盖**:人工运行会与
自动运行分开记录,方便对比。

## 10. 产物写在哪里

所有状态都在你选定的**项目目录**里:项目文件、每个数据集的工作目录、生成的脚本、运行记录与日志。
正常路径下程序不往你的原始数据目录写东西;删除项目数据走系统回收站(可恢复)。

**一个例外:NUS 坏采样点的清理发生在源头。** 程序会**就地改写**原始目录里的 `ser` 与 `nuslist`
(整行删掉坏点),改写前把原件复制成同目录的 `ser.bak` / `nuslist.bak`(`.bak` 已存在就不再覆盖),
日志里会写明 `Source cleanup …(backup .bak)`。它这样做是为了让重构拿到干净输入;**如果你的原始数据
是只读的,或者你不能接受原件被改写,请先自己复制一份** —— 源目录里的 `.bak` 就是你回退用的那一份。

## 11. 已知边界

- 真实处理需要外部 **NMRPipe**;NUS 重构还需要 **SMILE** —— 两者都不随本程序分发;
- 程序负责处理与留档,**不替你做科学结论** —— 统计分析、显著性与最终判断由你自己的流程完成;
- 峰重叠解耦、去卷积、结构解析/自动指认不在范围内;批量处理仅 2D;
- 处理结果建议用你自己的数据核对一遍(证据页见仓库 `docs/evidence/real-data-comparison.md`)。

## 12. 出问题先看哪里

1. **中栏任务日志**:失败原因通常写在这里(缺哪个可执行文件、内存在哪一步不够等);
2. `工具 → 数据质量检测`:先分清是「数据本身有问题」还是「处理参数不合适」;
3. 项目目录里的脚本、运行记录与 `log.txt`:每一步的输入、脚本与参数指纹都在;
4. 仓库里的 `docs/troubleshooting.md` 与 `docs/faq.md`。
