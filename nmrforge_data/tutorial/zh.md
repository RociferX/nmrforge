# NMRForge 使用教程

这份教程给第一次用图形界面的人:先看「能做什么」,再照一次典型会话从导入数据走到峰表。
菜单与按钮名称以程序里显示的文字为准(界面语言可在「设置 → 软件设置」切换,正文随之切换)。

本教程按当前源码更新。1.0.4 仅发布源码；已有 AppImage 仍为 1.0.2，不包含后续 API v1.1 更新。

## 1. 这个程序能做什么

- **读 Bruker 数据**:识别实验类型、采样方式(均匀 / NUS)与维度布局;
- **自动处理**:把原始数据转成 NMRPipe FID、再出谱;相位、基线、窗函数、零填充由程序选;
- **参数优化**:SMILE 参数扫描与排名(仅 2D NUS),可按「净真峰优先」或「留出残差优先」排序;
- **峰挑选与峰表**:自动选峰、三点抛物线亚像素定位(唯一方法),导出 POKY 风格 `.list`,谱图可导出 UCSF;
- **质量控制**:FID / 采样 / 谱图三级检查,运行结束时给分项报告;
- **项目与留档**:每个数据集的工作目录、生成的脚本、运行记录与日志都放在你的项目目录里;
- **数据组与批量**:把 2D 数据组织成组,一起处理;
- **人工路径**:任何生成的脚本都能打开、修改、直接运行。

## 2. 界面速览

窗口是**四列**,列边界都能拖:

- **第 1 列 · 项目树**:项目 → 实验 → 输入 / 处理 / 输出 / 图形。选中哪个节点,其余几列就跟着切换。
- **第 2 列 · 处理流水线**:当前数据集的面包屑,加上四个步骤,每步带状态和「下一步做什么」提示。
- **第 3 列 · 任务日志**:常驻的**中间竖列**,内容随当前选择变化。**失败原因通常写在这里。**
- **第 4 列 · 谱图**:内嵌查看器,以及当前上下文已经产出的谱图列表。

顶部菜单:`文件`、`实验`、`查看`、`工具`、`设置`、`帮助`(使用教程、关于 —— 使用教程就是这份文档)。

实验页的单条、分段和批量导入表单始终内嵌在页面里;页面较长时滚动该页即可找到导入区。单数据集、数据组和全局日志分别保存;单独处理组成员写入成员日志,整组处理写入组日志。

第 2 列顶部那行字就是**向导**:它按当前状态给出「下一步:生成谱图」「下一步:重跑 峰挑选」
「可选:SMILE 优化」或「全部步骤已完成」。

## 3. 标准流程:从新建项目到峰表

这就是每次处理一份数据的**主线**,照顺序走即可。带「按需」的小节是支线,不需要就跳过。

### ① 新建项目

`文件 → 新建项目...`,选一个目录(建议空的)。**所有产物都记在这个项目目录里**。
`文件 → 最近项目` 可以快速切回。

### ② 新建实验

`实验 → 新建实验...`。**实验类型可以先留空** —— 程序会用数据自己判定。

### ③ 导入数据

在实验页的单条导入表单中选择 **Bruker 数据目录**(里面有 `acqus`),也可以在第 1 列
**右键实验节点 →「导入样品数据...」**。只接受含 Bruker 参数文件的目录,选错当场提示。

数据是**分段采集**或**重复实验叠加**时,改用第 7 节的入口;要一次处理**多份 2D 数据**时,
用第 8 节的批量导入。

### ④ 核对程序识别的结果

第 2 列显示程序判出的**实验类型、采样分类(均匀 / NUS)与维度布局**,判定证据写在日志里。
**分类不对就现在改** —— 这是后面所有自动选择的依据(维度角色、处理路径、参数默认值)。

### ⑤ 生成 FID → 确定直接维范围(可选)→ 生成谱图

1. **点「生成 FID」的运行**。这一步需要机器上装了 **NMRPipe**;缺了会失败并说明。
   3D 数据按采样网格产出单文件或切片,由程序判断。
2. **确定直接维范围(可选,默认 6.5–10.5 ppm)**:点谱图步骤行上的**「直接维范围」**按钮。
   直接维就是 1H。**不改就直接用默认的 6.5–10.5 ppm**(宽窗、最稳);知道自己的峰在更窄的区间里
   (例如只有脂肪族区)时收窄窗口,能明显省时间与内存 —— 提取的点数少了,后面的零填充与
   NUS 重构都跟着轻。
   对话框里「**把这个范围也用于优化**」**默认是开**的:开着时优化与终跑用同一窗口(结果一致);
   关掉则优化仍用默认宽窗、只有终跑收窄。
3. **点「生成谱图」的运行**。**NUS 数据自动包含 SMILE 重构**。这一步最花时间与内存;
   数据质量检测会在优化之前先跑,结论写进日志。进度流式写进第 3 列日志。

### ⑥ 读运行报告

一次运行结束会给一份报告,包含三块:

1. **谱图质量分项**:信噪比 / 相位 / 基线 / 伪影;
2. **数据质量检测结论**(FID 与采样);
3. **最终实际用的处理参数** —— 包括程序自己选的那些,以及**直接维范围**与 **CAR 载频口径**。

**先看这里再看谱**:某项明显不对时,调参数重跑通常比反复看图更快。

### ⑦ 看谱

切换到样品数据时,第 4 列会自动显示当前数据的谱图;短暂防抖后启动加载,大型谱文件在后台读取。3D 谱默认显示 F3–F2 平面。
查看器里:

- **滚轮缩放**、**中键平移**、**强度滑块**调等值线;
- 可以**叠加多条谱**对比;点**峰表里的行**跳到对应峰;
- 3D 数据可按切片查看并显示投影。

放大比对时,左侧是参考谱,中间是当前谱;两侧的显示控件独立,绘图区等高。数值标签和单位在微调箭头外侧;
键入数字后按 Enter 应用,箭头或方向键仍按步长即时调整。纵横比可输入 `0.8` 这类小数,`0` 表示自由比例。

### ⑧ 按需:改谱中心 / 翻转间接维 / 其它自定义更改

看完谱常要做下面三件事之一,**都在这一步做,做完再去选峰**。

**情况 1 · 要改谱中心(载频 CAR)**

在**生成谱图步骤**打开人工脚本并修改 `CAR`,然后运行。程序会报告 CAR 的当前来源;默认策略按采集信息
配置载频,如需其它参考值,在生成谱图步骤手动编辑 CAR。改动会记入脚本差异报告,并使受影响的处理步骤过期。

**情况 2 · 要翻转间接维**

在谱图步骤行上**选好要翻转的维**,再点**「重新运行终脚本」**:

- **2D**:一个复选框「间接维(F1)」—— 勾选 = 加 `FT -neg`,取消 = 去掉。它是**状态**,
  按终脚本现状回填,不会把上次的翻转悄悄丢掉;
- **3D**:三项下拉 —— **间接维(F2)** / **间接维(F1)** / **F1和F2**。它是**命令**:
  选某项即翻转,**再选同一项 = 取消**,选完复位为「不翻转」。

翻转控件与重跑按钮在**同一个方框**里(读作「翻转 → 重跑」)。**什么时候要翻?**
谱图频率轴方向反了(峰位与预期镜像对称)就是这一维的符号问题。程序会按采集方式自动推断,
判不准的维在日志里提醒你手动确认。

**「重新运行终脚本」复用已生成的脚本,不重新优化** —— 相位、窗函数、基线、SMILE 结果都不动,
只按你指定的范围与翻转再跑一遍。3D NUS 只重跑**间接维那一段**;3D 均匀采样会重跑直接维,
所以看到提示时按它说的确认。

**情况 3 · 其它自定义更改**

走**人工**入口:打开对应步骤的脚本,想怎么改就怎么改,改完直接运行。成功运行后步骤报告会列出相对上次成功脚本
的命令与参数差异;失败运行会标为「尝试过的改动」,不把它当作成功结果。步骤失败时,步骤行上有**「查看日志」**
跳到日志位置。重跑或优化成功后会刷新对应数据的谱图,不会切换当前选中的数据。

### ⑨ 峰挑选

跑**峰挑选**:自动选峰并估计强度与 S/N。

**选的峰不合适时**(太多噪声峰 / 太少真峰):

1. **改阈值再选** —— 调峰挑选的参数(阈值等)重跑这一步;
2. **指定参考谱后再选** —— 点峰挑选步骤行上的**「参考谱」**,选一份**已有峰表**的数据作参考,
   参考可用时峰挑选**只保留与参考峰表匹配的峰**;参考不可靠或没有共同核素时会跳过过滤并保留检测到的峰。
   适合同一系列样品挑出**同一批峰**以便组间比较;
   旁边的**「清除」**取消这个约束。

### ⑩ 导出峰表与谱图

- **导出 POKY 样式峰表**:在谱图面板点 **`Export peaks`**。可选**直接导出**(原坐标)或
  **对齐后导出**(对选定参考峰表做整体平移对齐);格式是 POKY / Sparky 可读的 `.list`,
  别的软件能直接打开。也能用 `Import peaks` 从 `.list` 读回峰表。对齐只作用于导出的峰表,不会改动谱文件;
  匹配率低时会提示检查参考谱并跳过对齐导出,当前峰表和谱图保持原样。
- **找处理好的谱图**:在该数据集的**工作目录里的 `spectra` 文件夹**下 —— 那里有 NMRPipe
  终谱(`.ft2` / `.ft3`);**导出的 UCSF 谱图**也放在同一个 `spectra` 文件夹里,
  与终谱同名、扩展名换成 `.ucsf`。

## 4. 四个步骤各做什么

### 生成 FID

把原始 Bruker 数据用生成的 `fid.com`(内部调用 `bruker -AUTO`)转换成 NMRPipe FID。
**这一步需要机器上装了 NMRPipe。** 3D 数据按采样网格产出单文件或切片,由程序判断。
FID 转换脚本按采集参数生成,通常不需要改动;**CAR 在生成谱图步骤中查看或手动修改**。

### 生成谱图

按优化后的处理路径出终谱;**NUS 数据自动包含 SMILE 重构**。这一步最花时间与内存,日志会写实际
用了哪些参数。完成后出现**「展示谱图」**与**「重新运行终脚本」**。

### SMILE 优化(可选,仅 2D NUS)

对重构参数候选做扫描并排名,给出排序表和候选脚本。**它不会自动替换当前的活动谱** —— 看中哪个
候选再自己重跑。3D NUS 能正常处理,但界面不提供这条扫描。

### 峰挑选

自动选峰并估计强度与 S/N;亚像素定位只用三点抛物线,没有方法选择器。也可以**指定参考谱**约束只保留匹配的峰;
参考不可靠时会安全跳过过滤。
峰表能导出成 POKY 风格。

### 状态与「已过期」

每一步有六种状态:**未就绪**(前置条件没满足)、**可运行**、**运行中**、**已完成**、**失败**、
**已过期**。改了输入或参数之后,受影响的下游步骤会被标成「已过期」,而不是继续用旧产物 —— 重跑
那一步就行。

## 5. 看谱

- 第 4 列内嵌查看器:滚轮缩放、中键平移、强度滑块调等值线、叠加多条谱;
- 3D 数据可以按切片查看,并显示投影;
- **独立查看器**(不需要项目)也能单独启动:装好之后用 `nmrforge-viewer`,或 `python -m viewer`;
  支持把 `.ft2` / `.ft3` 文件直接拖进去。

## 6. 数据组与批量(仅 2D)

把数据组织成数据组,然后对整组一起处理。导入时勾选「批量导入并成组(仅支持 2D 谱)」,
或在项目树里右键数据组节点增删成员。**批量只支持 2D**:非 2D 数据会被跳过并说明原因;
单个数据集失败不会中断整组。

## 7. 分段采集 / 重复实验叠加的导入

一次采集被拆成几段(**分段 NUS**,各段互补拼满采样网格),或者同一个实验重复采了多次想叠加提高
信噪比时,用这条路:**不要**逐段当独立数据导入,而是让程序合并成**一条**样品数据。

**入口(两个,效果相同)**:

- 第 1 列**右键实验节点 →「导入样品数据...」**,在对话框里勾选
  **「分段数据或重复实验叠加导入(容器目录:多个含 acqus 的子目录合并为一条数据)」**;
- 或直接用实验页面导入区里的**「分段数据或重复实验叠加导入」**分组:填或选**容器目录**,
  点该分组的导入按钮。

**容器目录长什么样**:

- **顶层没有 `acqus`**,下面有 **≥ 2 个各含一套 `acqus` 的子目录**(每个子目录是一段);
- 程序会自己认出这种结构 —— 选到这样的目录时,导入对话框里的那个勾选会**自动打上**;
- 反过来,勾了但目录不是这种结构(不足 2 段),会明确告诉你,不会导入半份数据。

**导入后**:这些段**合并成一条数据**参与后续全部流程(只跑一次生成 FID / 生成谱图),
不会变成多条数据。重复实验叠加同理:按「同一套参数、同样的采样点」处理,叠加后信噪比更高。

## 8. 批量导入多份 2D 数据

要一次处理**多份各自独立的数据**时用这条路。
注意:这与第 7 节的「合并成一条」是**两件事**。

**入口**:实验页面导入区里的 **「批量处理」** 分组:

1. 点 **「添加数据文件夹...」** 逐个把数据目录加进列表(可以加多个),需要时用 **「清空列表」**;
2. **「批量导入并成组(仅支持 2D 谱)」默认是勾上的** —— 勾上时这些数据导入后进**同一个数据组**,
   之后可以对整组一起处理;取消勾选则不分组,等同于做了多次单份导入;
3. 点 **「批量导入」**,结束后给出汇总(总数 / 成功 / 失败)。

**批量处理的边界**:

- **只支持 2D**:3D 等非 2D 数据会被**跳过并说明原因**(请逐个处理);
- **失败按数据集隔离** —— 单份数据出错不会中断整组。

## 9. 工具菜单

- **数据质量检测**:检查原始 FID 的质量,结论在任何优化之前写进日志。**不依赖项目**,
  可以单独用来先分清「数据本身有问题」还是「处理参数不合适」;
- **谱图质量评估**:对已有谱图打分,给出分项与结论。

## 10. 设置

`设置 → 软件设置`:

- **界面语言**:跟随系统 / 中文 / 英文(按提示重启程序生效;`NMRFORGE_LANG` 可临时钉死一次运行);
- **NMRPipe 路径**:留空则自动查找(PATH、`~/.cshrc` 里的 `NMRPIPEBIN`、常见安装目录);
- **数据目录**:导入对话框的浏览起点;
- **各核默认线宽**与**对齐容差**:影响自动优化与峰匹配的判据;
- **SMILE 线程数**:默认 2,上限是「机器核数 − 2」;调高更快也更吃资源,NUS 重构建议保守。

设置写进本地覆盖配置,重启后生效。

## 11. 产物写在哪里

- **峰表**:用 `Export peaks` 导出时选位置,格式是 POKY / Sparky `.list`;
- **谱图**:在该数据集工作目录的 **`spectra` 文件夹**里 —— NMRPipe 终谱(`.ft2` / `.ft3`)与
  导出的 **UCSF** 谱图(与终谱同名、扩展名 `.ucsf`)都在这里;
- **其余状态**:项目文件、每个数据集的工作目录、生成的脚本、运行记录与日志,都在你选定的
  **项目目录**里;删除项目数据走系统回收站(可恢复)。

**一个例外:NUS 坏采样点的清理发生在源头。** 程序会**就地改写**原始目录里的 `ser` 与 `nuslist`
(整行删掉坏点),改写前把原件复制成同目录的 `ser.bak` / `nuslist.bak`(`.bak` 已存在就不再覆盖),
日志里会写明 `Source cleanup …(backup .bak)`。**如果你的原始数据是只读的,或者不能接受原件被
改写,请先自己复制一份** —— 源目录里的 `.bak` 就是你回退用的那一份。

## 12. 已知边界

- 真实处理需要外部 **NMRPipe**;NUS 重构还需要 **SMILE** —— 两者都不随本程序分发;
- 程序负责处理与留档,**不替你做科学结论** —— 统计分析、显著性与最终判断由你自己的流程完成;
- 峰重叠解耦、去卷积、结构解析/自动指认不在范围内;批量处理仅 2D;
- 处理结果建议用你自己的数据核对一遍(证据页见仓库 `docs/evidence/real-data-comparison.md`)。

## 13. 出问题先看哪里

1. **第 3 列任务日志**:失败原因通常写在这里(缺哪个可执行文件、内存在哪一步不够等)。
   失败步骤行上有**「查看日志」**按钮直接跳过去;
2. `工具 → 数据质量检测`:先分清是「数据本身有问题」还是「处理参数不合适」;
3. 项目目录里的脚本、运行记录与 `log.txt`:每一步的输入、脚本与参数指纹都在;
4. 仓库里的 `docs/troubleshooting.md` 与 `docs/faq.md`。
