# Provenance of the vendored licence texts

These files are verbatim copies of the canonical GNU licence texts, fetched so that every built
AppImage carries them. Verify them with:

    python scripts/check_third_party_licenses.py

Fetched: 2026-09-16. The texts are unmodified; the GPL-3.0 text is required because LGPL-3.0
incorporates it by reference ("This library incorporates the terms and conditions of the GNU
General Public License, version 3").

This file is the input for the build-time and CI checks, so both the build and the test suite fail
if a text is missing or altered.
